# Brains: one per person whose voice the brand speaks in
A brain = identity profile, life timeline, journal and story cards for a founder, spokesperson, creator or client.
- `brains/klaus/` — Klaus (operator, TITAN.AI; voice of Physio Spot and his personal channels)
- `brains/_template/` — copy to `brains/<slug>/` for a new person (`/onboard` does this)
Active brain: `.studio/active_brain` (one line, slug). Skills and agents read `brains/<who>/` where `<who>` = that slug.
Faceless brands skip the brain and use the brand file's voice section.
Privacy: real journals, client stories and family details only in a PRIVATE repo; media stays in Drive.
