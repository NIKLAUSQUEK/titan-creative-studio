Look up a creator style preset. Query Supabase (titan-os, ref qdikcsxinpyfnljszvay): select c.name, s.card_md, s.dna from style_cards s join style_creators c on c.id=s.creator_id where c.name ilike '%$ARGUMENTS%'. If no card yet, fall back to the draft row in library/Creator_Style_DNA_Library.xlsx and say it is unverified. Summarise as a one-tap preset (vibe, energy, camera, lighting, pacing, captions, voice, Higgsfield translation). For edits of real footage, also save the dna JSON to a file and run `python tools/editor/editor.py preset from-stylecard "<name>" --file <file>` to get a `style-<creator>` editor preset.
