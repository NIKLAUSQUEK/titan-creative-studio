# Carousels, static posts, ad statics, thumbnails and infographics

This file supersedes the short `higgsfield-creative-director/references/playbook-carousel.md`; that file stays as the quick spec. Researched 2026-10-25; sources are in `research/sources-agency-playbooks.md` §3.

Labels:
- **[P]** platform or executive statement
- **[S]** secondary study
- **[R]** design research
- **[RoT]** rule of thumb

## 1. Why carousels work, and when to choose one
- **Second chance [P, reported second-hand].** Mosseri has said an unswiped carousel is often re-served starting at slide 2. Slide 2 is therefore a second cover and must hook on its own.
- **Ranking [P].** Watch time, likes and **sends per reach** are the top Instagram signals. Swipes build time spent, reference slides earn saves, and relatable slides earn sends (platform-signals.md).
- **Data [S].**
  - Socialinsider 2026 (67.5M posts): carousels 0.55% engagement vs Reels 0.52% and images 0.37%. Carousels win saves (above 10k followers) and views per post; Reels win comments.
  - Buffer, via secondary coverage: carousels get about 114% more engagement than single images. Reels get about 39% more reach. LinkedIn carousels far out-engage LinkedIn video and images.
- **Rule.** Reels reach new people; carousels deepen engagement with people who already know you. Run both.

**Choosing a format.** Pick a **carousel** for reference material, steps, lists, comparisons, data, a warm audience, or LinkedIn B2B. Pick a **reel** for a demo, personality, sound, or reaching new people.

**Waterfall:**
- Every hero reel becomes a key-frame carousel.
- A carousel that saves well becomes a TikTok Photo Mode post with music, plus a LinkedIn PDF.

| **Meta ads** | 4:5 feed, 9:16 Stories/Reels, 1:1 fallback. Safe zones: keep about 14% at the top and 20% (Stories) to 35% (Reels) at the bottom clear, plus about 6% at each side. Check against the Ads Manager overlay. |

Default length:
- Instagram: **7–10 slides**.
- LinkedIn: 8–12 slides.
- TikTok: 5–9 slides (swipes are fast).

## 3. Sixteen archetypes (slide-by-slide)
| # | Archetype | Template | Best for |
|---|---|---|---|
| 1 | Listicle | Hook with a number → re-hook ("#1 you do 200×/day") → one item per slide (headline + one-line why + mini visual) → recap grid + save CTA | everything |
| 2 | Step-by-step | Outcome promise → who it's for / what you need → numbered steps with a "common error" sticker → full sequence on one slide → save + try | exercises, recipes, AI workflows |
| 3 | Myth vs fact | "Stop believing these 5…" → MYTH slide (red strike-through) → FACT slide (green check + tiny source), repeated → "Which surprised you?" | protein, physio |
| 4 | Mistake → fix | "You're doing X wrong" → why it matters → ❌/✅ split pairs → checklist → CTA | fitness form, prompts |
| 5 | Framework | Name it → the problem it solves → full diagram → one element per slide → worked example → diagram again ("screenshot this") → CTA | AI agency, founder |
| 6 | Story | In-scene tension moment → one beat per slide, photo-led, 1–2 lines → lesson → how it applies to you → follow | founder |
| 7 | Before / after | ⚠️ **Never body or treatment results for SG health.** Only workflow, setup or routine before/after | AI agency |
| 8 | Comparison table | "X vs Y: which is right for you?" → criteria → one criterion per slide → full table → "Choose X if…" → CTA. Compare categories, never named competitors with superlatives | protein types, AI tools |
| 9 | Data / infographic | Big stat + source → why it matters → one chart per slide, directly labelled → so-what → sources slide → CTA | physio, AI |
| 10 | Checklist / cheat sheet | Title → grouped checklists → whole sheet on one screenshot-friendly slide → save | all |
| 11 | Case study (non-testimonial) | Problem pattern ("a common presentation") → what we assess → what research says → typical pathway → "timelines vary / see a professional" → learn more. **No patient quotes, outcomes or photos**; a labelled composite | physio |
| 12 | Quote / thought leadership | Bold contrarian line → one point per slide in large type → counter-argument acknowledged → conclusion → "Agree or disagree?" | founder, B2B |
| 13 | "Save this" reference | "Bookmark this for your next ___" → dense, ordered tables, swaps or prompts → everything on one slide | protein, AI prompts |
| 14 | Product feature | Benefit hook (not the product name) → problem → one feature = one benefit + close-up per slide → how to use → specs/FAQ → where to buy. No disease claims | protein, apparel |
| 15 | Meme | Relatable template → escalating variations → branded twist → "send to a friend who…" (built for sends) | fitness, founder |
| 16 | Tweet-style / text-only | Screenshot-style card, one thought per slide → summary | founder, LinkedIn |

## 4. Hook, re-hook, swipe devices, CTA, caption
**Slide 1 (the cover)**
- 4–10 words, ideally ≤8. People scan headings and rarely read body copy (NN/g F and layer-cake patterns) [R].
- Headline formulas:
  - number + outcome + time
  - the mistake
  - contrarian
  - identity callout ("If you run 3×/week…")
  - curiosity gap with the payoff promised
  - versus
  - reference bait
  - story open
- Visual tension: pick **one** of
  - a face looking at the camera or the text
  - an object mid-action
  - something visibly wrong
  - a striking number
  - a ❌/✅ contrast
- Faces: test them, don't assume them. 1of10's analysis of 300k+ videos found no overall advantage for faces; multiple faces beat a single face; the effect depends on the niche [S].
- Cover checklist:
  - [ ] readable at thumbnail size
  - [ ] inside the 3:4 crop
  - [ ] brand distinctive asset present
  - [ ] swipe cue present

**Slide 2.** A standalone re-hook: a more specific promise or an immediate quick win. Never an "about me" intro.

**Swipe devices**
- An arrow on slide 1 only.
- A progress indicator ("3/9").
- Cliffhanger cut-offs ("The fix is surprisingly simple…").
- Elements that cross the slide edge.
- Seamless panoramic carousels (10800×1350 sliced into 1080 px panels, important text kept off the cut lines). Use for brand moments, not every post.
- Numbered teases ("#7 is the one nobody does").

**Last slide.** **One** CTA, matched to the goal:
- Save (reference content)
- Send ("send to your gym buddy"; sends drive reach)
- Comment a keyword (only with compliant DM automation, and never as an inducement for health services)
- Follow for part 2

Put a smaller recap on the second-last slide. SG clinics: an informational CTA ("Learn more about our physiotherapy services").

**Caption**
- The first ~125 characters add *new* information beyond the cover.
- Then 2–4 lines, the CTA repeated, and 3–5 relevant keywords/hashtags (Instagram caps hashtags at 5).
- Alt text on at least slides 1–3.
- LinkedIn: the post text carries the hook, and the PDF title reads like a headline.

### Pre-validated teardown (before writing any carousel or post)
Take 3–5 posts that over-performed in the niche and tear each down on three axes. **Adapt the structure to our ICP; never copy wording or visuals.**
- **Hook:** what stops the scroll.
- **Idea:** the core tension.
- **Format:** the layout.

Format bank to add to §3:
- **Three-column comparison:** e.g. whey vs plant vs collagen, or ChatGPT vs Claude vs Gemini.
- **Decision tree:** "Should I see a physio? Yes / no path", educational only.
- **Expectation vs reality:** top/bottom split.

## 5. Visual system (1080×1350 canvas)
**Grid**
- Margins of 80–100 px.
- 6 columns with a 24 px gutter.
- Fixed zones: headline (top third), content, and a footer strip (handle, logo, progress; 60–80 px).
- The same template on every slide makes the series recognisable.
- TikTok 9:16: keep text out of the bottom ~25% and the right ~15%.

**Typography**

| Element | px on a 1080-wide canvas |
|---|---|
| Cover headline | 90–140, bold/black, ≤8 words, ≤3 lines |
| Slide headline | 64–90 |
| Body | **36–44 (never below 32)**, ≤25–30 words per slide (LinkedIn ≤40) |
| Labels / sources | 24–28 |

- A 1080 px slide displays about 0.36× on a phone, so 40 px body text lands near the ~14–16 pt mobile minimum.
- Line length about 35–45 characters.
- Line height 1.15 for headlines, 1.3–1.4 for body.
- ≤3 levels of hierarchy.
- One display face plus one legible sans, locked in `brands/<brand>.md`.
- No thin weights over photos.

**Colour and contrast**
- WCAG 2.x: at least 4.5:1 for normal text and 3:1 for large text [P]. Aim for 7:1 for body text over anything busy (glare and compression).
- Text over photos: a 40–60% black scrim, a solid block, or negative space.
- At most one accent colour per slide.
- Red = myth/mistake, green = fact/fix, **always paired with an icon** for colour-blind viewers.

**Distinctive assets.** Ehrenberg-Bass (Romaniuk): an asset counts only if it scores on fame *and* uniqueness.
- Pick 2–3 per brand: a colour block, a frame or corner device, a mascot, a series name ("Desk Fix Friday"), footer placement.
- Use them on every slide 1 and every ad, unchanged.
- Avoid category clichés: generic physio blue, protein-tub explosions, AI purple gradients.

**Imagery**
- **Real photos of real staff, clinic, product and founder come first** (hard rule).
- Illustration or 3D for anatomy and frameworks.
- AI images only for backgrounds, metaphors or product scenes, never presenting fake staff, patients or reviewers. There is no strong data on audience penalties for AI images, so A/B test.
- Data visuals: label values directly, one message per chart, sources on the slide.
- **One idea per slide.** More than ~30 words means split it, except for a deliberately dense "save this" summary slide.

## 6. Ad statics (Meta, TikTok)
- **Creative is the targeting.**
  - Meta's Andromeda-era guidance is creative *diversification*: different personas, angles, concepts and formats, not colour tweaks (Jon Loomer 2025, citing Meta).
  - Motion's 2026 benchmarks (550k ads, about $1.3B spend): only **5–8% of ads become real winners**, and about half never get meaningful spend. Plan for volume.
- **Text on images.** The 20% rule is gone. Text-led statics (big number, native note) can win if they're readable at feed size.
- **Advantage+ creative enhancements:** accept brightness and crops, but **turn off text and generative changes for SG health brands**. Review previews weekly.

**Proven layouts**
1. **Us vs them:** ✅ vs ❌ against "the usual way", never a named competitor or superlative.
2. **Feature callouts.**
3. **Problem/solution split:** physio OK if educational with no promise.
4. **Big number:** substantiated stats only.
5. **Native look:** notes app, iMessage, whiteboard, search bar. Never fake notifications or misleading UI.
6. **Meme:** not for clinic paid ads.
7. **UGC/review screenshot:** ⚠️ **never for SG health**. For others, only genuine consented reviews.
8. **Offer card:** ⚠️ no discounts or free consults for SG health.
9. **Founder quote card.**
10. **Checklist/infographic:** fits clinics ("5 signs your back pain needs a physio").

**Text pairing**
- The image carries the ≤8-word hook.
- Primary text adds a *different* angle in its first 125 characters.
- The headline field states the offer or benefit in ≤40 characters.
- The CTA button matches intent: Learn More for clinics, Shop Now for protein.

**Testing**
- Each batch: 3–5 concepts × 2–3 executions.
- Judge on cost per result, with thumb-stop rate and CTR as early diagnostics.
- Kill after about 2× target CPA with no conversions [RoT].
- Iterate a winner one variable at a time.
- Log results to `/review` → `/learn`.

## 7. Thumbnails and covers
**YouTube**
- **Test & Compare** [P]: up to 3 titles and/or thumbnails. The winner is chosen by **watch-time share**, not CTR, so clickbait loses. Not available for Shorts, Lives or Premieres. More-different variants finish faster.
- Rules:
  - One focal point, readable at about 160 px wide.
  - ≤3 words of text [RoT].
  - Faces: test them; real emotion that matches the content.
  - High contrast against YouTube's white and dark UI.
  - The thumbnail shows the *situation*; the title adds the *information*. Never repeat the title on the thumbnail.
  - Honest curiosity gap.
  - Keep the bottom-right clear (timestamp).
  - 1280×720, under 2 MB.
- Always upload 3 contrasting variants.
- Workflow: `higgsfield-youtube-thumbnail` skill, then vidIQ `vidiq_score_thumbnail`.

**Reel/TikTok covers**
- 1080×1920 with the title inside the centred 3:4 box.
- 3–6 words of large type, a series template, a distinctive-asset colour.
- Plan the grid rhythm: alternate face / text / product, and colour-code series.

## 8. Production workflow
1. **Master template per brand** (Canva brand kit or Figma components): cover, re-hook, content variants (text / photo + text / chart / ✅❌ split / quote), recap, CTA, footer with progress. Export 1080×1350 PNG, or PDF for LinkedIn. The `edit-brand` block is the source of truth.
2. **AI images.** Generate **imagery without text**, then set all type in Canva or Figma: spelling stays exact, text stays editable, and localisation (EN/MS/VI/ZH) becomes a text swap. Model routing:

   | Need | Model |
   |---|---|
   | Text rendering when unavoidable, including diacritics and CJK | GPT Image 2.5 |
   | Layout and type control | Ideogram |
   | Vectors | Recraft |
   | Consistent characters, edits with references | Nano Banana |

   - Lock a style key (prompt + references + seed) per series.
   - Generate a carousel's slides in one session.
   - Drafts at the lowest quality first (credit rule).
3. **Batch.**
   1. Monthly topic bank from `/calendar`.
   2. Write copy for 8–12 carousels in one sitting (sheet columns: slide#, headline, body, visual note, alt text).
   3. Fill templates from the CSV (Canva/Figma connectors).
   4. Generate images by style key.
   5. QC.
   6. `/publish`.

   Each carousel also becomes: 1 TikTok Photo Mode post + 1 LinkedIn PDF + 2–3 statics + 1 ad static.
4. **QC** (run `scripts/qc_frames.py` and view the contact sheet at about 25%):
   - [ ] headline readable; body ≥36 px
   - [ ] contrast ≥4.5:1; scrims on photos
   - [ ] safe zones and 3:4 crop respected
   - [ ] one idea per slide, ≤30 words
   - [ ] slide 2 hooks on its own; one CTA
   - [ ] every number checked against its source; sources slide present
   - [ ] distinctive assets on slide 1
   - [ ] compliance: no testimonials, before/after, superlatives, free/discount inducements, outcome promises or disease claims
   - [ ] Advantage+ text and generative enhancements off for SG health
   - [ ] real people are real and consented; no garbled AI text
   - [ ] alt text written; first caption line adds new information; native-speaker check (MY/VN/ZH)
   - [ ] licensed music only on brand accounts
