# Script interrogation checklist
Extract first, ask second. Ask max 3 tappable questions per round (ask_user_input_v0); nuance in free text. Never ask what the brand file or ledger already answers.

## A. Intent
1. What should the viewer feel/do in the last second? (laugh+follow, book a session, buy, DM keyword)
2. One-sentence idea/punchline - restate it back. Does every shot serve it?
3. Platform + format + length (TikTok/Reels 9:16 15-30 s; carousel 4:5 6-10 slides; YouTube 16:9).
4. Brand: heal360 / TITAN.AI / Power Protein / personal channel / client (which)?

## B. Story mechanics
5. Whose story? Who is the "camera"? (POV owner per shot)
6. Beat sheet: hook (<=1.5 s) -> setup -> turn -> payoff -> button/CTA. Missing beat?
7. Is the physical action consistent with the line? (e.g. "spot me" requires the lifter actually pressing a loaded bar)
8. Where is everyone standing? Draw the set map. Any object that must be in every shot?
9. Dialogue: exact words, who says them, tone, accent, pace. Does it fit the shot length (~2.5 words/s)?

## B2. Gag mechanics (ask EVERY time there is a joke)
- Whose body / prop / wardrobe does the gag live on?
- Is any line a pun or double meaning? What is the second meaning?
- What must the audience NOT see before the payoff?
- Does prior footage of this concept exist? Treat its staging as intent, not error.

## C. Talent and look
10. Real people (Klaus/Physio Niklaus, staff, client) or original AI characters? Photos available for Soul/Element?
11. Wardrobe and brand colours on talent?
12. Reference: a video/image whose look, pacing or camera you want matched?

## D. Risk
13. Medical/health claims (heal360): anything that needs softening or a disclaimer?
14. Moderation risk in the gag? Propose a safe restage.
15. Budget ceiling for this asset (credits) and deadline.

## Interrogation output
Return a "Here's what I understood" block: logline, beats, cast, set map, open questions. Only proceed when the user confirms or answers.
